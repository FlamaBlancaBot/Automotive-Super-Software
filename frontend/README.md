# Automotive Super Software — Frontend

React + Vite frontend for the Automotive Super Software internal garage management app.

## Quick start

```bash
npm install
npm run dev
```

## Branding (logo/favicon)

- Replace `public/brand/logo.svg` when you have a real logo.
- Replace `public/favicon.svg` when you have a real favicon.
- Update simple defaults in `src/config/branding.js`.
